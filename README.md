# Cmd Control 暗黑三国

一个面向 **PAL-LX9 / 2200×2480 / 横屏手机浏览器** 的暗黑三国横版动作原型，使用 **原生 JavaScript + HTML5 Canvas**。当前版本参考“三国群英传 OL”方向，突出主将带亲兵推进、点敌锁定、普攻、无双技能、集结亲兵和攻破营门的核心循环。

## 环境要求

任选一种运行环境即可：

- **Python 3**：推荐给只有手机、没有 Node.js/npm 的情况
- Node.js 20 + npm 10：适合电脑或完整开发环境
- 手机或桌面浏览器；目标设备为 PAL-LX9，建议横屏游玩

## 手机只有 Python 3 时怎么运行

在项目目录执行：

```bash
python3 run_game.py
```

启动后，在同一台手机浏览器打开：

```text
http://localhost:5173
```

如果端口被占用，可以换一个端口：

```bash
python3 run_game.py --port 8000
```

然后打开：

```text
http://localhost:8000
```

## Node.js / npm 运行方式

```bash
npm run dev
```

启动后打开终端中显示的本地地址即可开始开发，默认地址是 `http://localhost:5173`。

如果要让另一台手机访问电脑上的开发服务器，请让手机和开发电脑处于同一个局域网，然后用电脑的局域网 IP 访问，例如：

```text
http://你的电脑局域网IP:5173
```

## 常用命令

```bash
python3 run_game.py                 # 用 Python 3 启动游戏，适合手机
python3 -m py_compile run_game.py   # 检查 Python 启动脚本语法
npm run dev                         # 用 Node.js 启动本地开发服务器
npm run build                       # 检查 JavaScript 语法
npm run preview                     # 使用 Node.js 静态服务器预览当前版本
```

## 当前玩法

- 手机摇杆：左下虚拟摇杆控制主将上下左右移动
- 手机触屏：点击地面移动，点击敌军锁定并自动尝试攻击
- 手机按钮：`斩` 普攻，`无双` 范围爆发，`集结` 召回并治疗亲兵
- 键盘测试：`WASD` / 方向键移动，`J` 普攻，`K` 无双，`L` 集结，`R` 重新开始
- 目标：带领亲兵击破黄巾军，积攒怒气释放无双，最终攻破营门

## 已按你的手机配置调整
